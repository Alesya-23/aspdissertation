# Разбор проекта
Продукт - RAG система по уголовному праву. Это научный проект, в котором мы будем проводить эксперименты и делать выводы. Планируется, что в результате мы сможем задовать модели вопросы - она будет отвечать, опираясь на нашу векторную базу данных(уголовное право).

## Где что лежит

- `init.py` — код развертывания модели, только чтение
- `speeches/` — файлы созвонов, читать их каждый раз не нужно, только по запросу.
- `out/` — разборы, по файлу на интервью. Имя файла совпадает с исходником.
- `requirements` - здесь мы фиксируем как будет выглядеть наше решение(стек технологий, сравнение характеристик и т.д.). Пока что структура файла на твой вкус. 

# Стек
Стек проекта - язык Python и вспомогательные библиотеки, необходимые для работы программы. 

## Что считается выводом по разговору

Вывод — это утверждение от пользователе, под которым стоит дословная цитата
с таймингом. Без цитаты это не вывод, а моя догадка, и в отчёт она не идёт.

## Чего не делать

- Не пересказывать цитаты своими словами. Дословно или никак.
- Не обобщать все обсуждения - только по отдельности.
- Не выносить файлы созвонов и расшифровки: там данные, которые пока рано выносить в публичное поле, там люди с именами.
